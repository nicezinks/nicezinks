Olá! Eu sou um desenvolvedor **Full Stack** apaixonado por tecnologia, programação e desenvolvimento de software. Tenho **13 anos** e estou sempre estudando, criando novos projetos e buscando evoluir como programador. Desde que comecei a aprender programação, descobri que desenvolver aplicações é algo que realmente gosto de fazer. Por isso, dedico grande parte do meu tempo livre para estudar, testar novas tecnologias e transformar ideias em projetos reais.

Minha principal linguagem é **Python**, onde concentro praticamente todos os meus estudos e desenvolvimento. Utilizo Python para criar aplicações desktop, ferramentas, utilitários, sistemas completos, automações, bots, APIs, projetos Open Source e diversas outras soluções. Meu objetivo é sempre escrever códigos organizados, reutilizáveis, rápidos e fáceis de manter, seguindo boas práticas de desenvolvimento.

Além do Python, também possuo conhecimentos em **HTML5**, **CSS3** e **JavaScript**, tecnologias que utilizo para desenvolver interfaces modernas, sites, dashboards, painéis administrativos e aplicações web responsivas. Gosto de unir um design agradável com funcionalidades úteis, buscando sempre proporcionar uma boa experiência para quem utiliza meus projetos.

Também estudo **Java**, linguagem na qual possuo conhecimentos de nível júnior e continuo evoluindo constantemente. Acredito que conhecer diferentes linguagens amplia minha visão sobre programação e ajuda a desenvolver soluções melhores para diferentes tipos de problemas.

Tenho interesse em diversas áreas do desenvolvimento de software, incluindo desenvolvimento desktop, desenvolvimento web, APIs, automações, ferramentas, bibliotecas, sistemas personalizados e projetos Open Source. Sempre que possível procuro aprender novas tecnologias, testar novos frameworks e conhecer diferentes maneiras de resolver um mesmo problema.

Meu principal objetivo é evoluir continuamente como desenvolvedor, criando projetos cada vez mais completos, organizados e profissionais. Cada projeto publicado representa uma nova oportunidade de aprender algo diferente, melhorar minhas habilidades e compartilhar conhecimento com a comunidade.
